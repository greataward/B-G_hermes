# Fixtures

Real files from the line, used as test input. Keep them unedited.

Encoprint keeps one work order per UPC, so add one folder per UPC work
order, named after the order and UPC, e.g. `200112021-618842550500/`,
containing:

- the Encoprint export for that work order
- `entered.txt`: what was entered by hand for each of that UPC's rolls in
  the Production Planner, QC file and Sage (lots, quantities, scrap, date,
  initials)
