# Fixtures

Real files from the line, used as test input. Keep them unedited.

For each roll, add a folder named after the order and roll, e.g.
`200112021-roll5/`, containing:

- the Encoprint export for that roll
- `entered.txt`: what was entered by hand for that roll in the Production
  Planner, QC file and Sage (lots, quantities, scrap, date, initials)
