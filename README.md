# Hermes

Automates data entry for the high-speed RFID label line at B&G: the
operator scans lots and marks rolls complete, and Hermes fills in the
Production Planner, the QC file and Sage.

- `SPEC.md` — what Hermes does and how
- `phase0/` — investigation checklist and findings (current phase)
- `fixtures/` — real files from the line, used as test input

No code yet: Phase 0 is investigation only.
